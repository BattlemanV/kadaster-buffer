# Буфер участка (KadBuffer)

Десктопное приложение (Windows, Qt5/QML): по кадастровым номерам
земельных участков и буферу в метрах от их границ собирает из НСПД
соседние земельные участки в буферной зоне, показывает их на карте и в
таблице и выгружает отчёт в Word по форме раздела СЗЗ.

Таблица на экране:

* № — постоянный номер участка (по расстоянию, ближайший = 1); тем же
  номером участок подписан на карте, кадастровый номер — в подсказке;
* кадастровый номер;
* румб (С, СВ, В, ЮВ, Ю, ЮЗ, З, СЗ) — от центроида ближайшего исходного
  участка к центроиду соседа;
* расстояние от границы исходного участка до границы соседнего
  (минимальный зазор между контурами; 0 — смежные участки);
* назначение — разрешённое использование; если источник его не отдал,
  подставляется категория земель.

Отчёт Word (`Документы\KadBuffer\exports\<номер> буфер <N> м.docx`):
абзац о ближайших территориях с нормируемым качеством воздуха по румбам
(черновой — нормируемость определяется по ключевым словам назначения) и
таблица всех участков зоны с площадью, по площади от большей к меньшей.

## Стек

* Windows 10/11 x64, Qt 5.15 (MinGW), CMake
* Карта: QtLocation (плагин `itemsoverlay`), подложка — карта НСПД
  `/api/aeggis/v4/235/wmts/{z}/{x}/{y}.png`, свой слой тайлов + TileDiskCache
* Данные: НСПД (`nspd.gov.ru`). Поиск участка по номеру —
  `/api/geoportal/v2/search/geoportal`, соседи —
  `POST /api/geoportal/v1/intersects?typeIntersect=fullObject`
  (слой земельных участков `36368`, геометрия в EPSG:3857)
* Отчёт: `qml/components/Reports.js` строит XML частей .docx,
  `ExportFileHelper::writeZip` (C++, zlib из QtCore) пакует их в zip.
  Python и сторонние библиотеки не нужны.
* Настройки (цвета и штриховка слоёв): `%APPDATA%\KadBuffer\KadBuffer.ini`.

## Сборка

```
mkdir build-release && cd build-release
cmake .. -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
mingw32-make
```

**Путь к проекту с кириллицей** (например, `C:\Users\Иван\...`) ломает
AutoMoc CMake под MinGW («AutogenInfo.json is not readable»). Собирайте
через временный диск: `subst K: "<папка проекта>"`, затем `cmake K:/ ...`
в `K:\build-release` (диск пропадает после перезагрузки; снять — `subst K: /d`).

`runtime/` — среда выполнения Visual C++ для OpenSSL (он собран MSVC):
`vcruntime140.dll` 14.28 (поддерживает Windows 7) и Universal CRT из
Windows SDK 10.0.10240 (`Windows Kits\10\Redist\ucrt\DLLs\x64`). Локальный
актив, не в git; копируется рядом с exe. Без него на машине без «Visual C++
Redistributable» https не работает: «TLS initialization failed».

`openssl/` — локальный бинарный актив (DLL OpenSSL 1.1, не в git),
копируется рядом с exe шагом POST_BUILD. Без него https (карта и
кадастр) падает с "TLS initialization failed" на чистых машинах.

Дистрибутив и установщик:

```
powershell -ExecutionPolicy Bypass -File tools\make-dist.ps1
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" installer\kadbuffer.iss
```

`make-dist.ps1` собирает `dist\` из `build-release\` по белому списку —
только модули Qt, которые приложение реально загружает (около 66 МБ).
Установщик — `installer\output\KadBuffer-Setup-<версия>.exe` (около 16 МБ).
Программный OpenGL (`opengl32sw.dll`) намеренно не входит: на машинах
без драйвера OpenGL работает ANGLE (Direct3D). `D3Dcompiler_47.dll` для
ANGLE входит в состав: в Windows 7/8 его нет в системе.

## Важные оговорки

* Кадастровые API НСПД — **неофициальные**. Формат ответов может
  измениться без предупреждения (ровно это случилось с ПКК, см. ниже).
* **С машины разработки API недоступны** — `nspd.gov.ru` уходит в
  таймаут (VPN либо гео-блокировка). Интеграция проверяется
  только с машины оператора, по логу из встроенной консоли (F12).
* **ПКК больше не используется.** `pkk.rosreestr.ru/api/features/1`
  переадресует на НСПД и отдаёт HTML-оболочку веб-карты вместо JSON.
  Поиск соседей — НСПД `/intersects` (его же использует инструмент
  «найти пересечения» в веб-клиенте НСПД). Лимит ответа `/intersects`
  неизвестен: в консоли печатается, сколько участков пришло.
* Сайт НСПД подписан российским корневым сертификатом Минцифры («Russian
  Trusted Root CA»), которого нет в Windows по умолчанию. Он встроен в
  программу (`resources/certs/`, `src/nspdssl.*`) и добавляется к системным —
  проверка сертификатов остаётся строгой.
* Запросы идут через C++ `CadastralHttp`, не через QML `XMLHttpRequest`:
  Qt вырезает из XHR заголовки `Referer` и `User-Agent`, а WAF НСПД без
  `Referer` отвечает 403. Тайлы подложки качает `TileDiskCache` с тем же
  Referer.
* Буферная зона — настоящий многоугольник, повторяющий контур участка
  (`GeoMath.bufferRingM`): поле знаковых расстояний + marching squares,
  затем упрощение Дугласа—Пекера. Площадь сверена с аналитической
  `A + P*buf + pi*buf^2` на выпуклых контурах — расхождение менее 1%.
* При нескольких исходных участках строится **своя зона на каждый**
  (`bufferRings`). Если ни одна зона не построилась, подставляется
  прямоугольник — чтобы область поиска была видна.
* В запрос `/intersects` уходит прямоугольник bbox + буфер: он заведомо
  накрывает зону. Отбор соседей — по настоящему зазору между контурами
  (`minDistanceRingsM`), поэтому НСПД отдаёт больше участков, чем
  попадает в таблицу.
* Имена атрибутов НСПД не документированы, поэтому назначение ищется по
  широкому списку кандидатов (`PURPOSE_KEYS`, `CATEGORY_KEYS`), а затем
  по шаблону ключа. Атрибуты первого соседа печатаются в консоль.

## Диагностика

Консоль скрыта, открывается по **F12** (кнопка «Копировать» — для
отправки лога). Обработчик сообщений Qt ставится до загрузки QML, поэтому
в буфер попадают и ошибки старта.

Каждый запрос пишет HTTP-код, размер тела, `Content-Type` и время в мс;
каждая неудача — причину и фрагмент ответа. Отказы тайлов подложки —
строки «Тайл не загружен: … HTTP …».

Проверка с НСПД — на реальном участке из своей работы (номера реальных
объектов в репозиторий не кладём; в примерах — `38:00:000000:N`).

Проверка без запуска приложения:

```bash
qmllint qml/Main.qml qml/components/*.qml qml/components/*.js
node tools/verify-buffer.js      # буферный полигон против аналитики
# интерфейс: настоящий Main.qml, вымышленные участки, клики мышью
PATH="build-release:/c/Qt/5.15.2/mingw81_64/bin:$PATH" qmltestrunner.exe -input tools/qmltest/tst_main.qml
```

Новую функцию интерфейса — описывай в `docs/manual.html`.

Правка в `qml/` попадает в приложение **только после пересборки** — QML
зашит в `.qrc`. Запущенное приложение держит exe, и линковка падает с
`Permission denied`: закрыть окно перед сборкой.
